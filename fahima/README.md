# فهيمة — Fahima Android prototype

نسخة تأسيسية قابلة للبناء والتثبيت، هدفها تثبيت قاعدة المشروع قبل ربط المحركات السحابية.

## الموجود فعليًا في 0.1.0
- واجهة عربية واحدة باسم فهيمة.
- شخصية مرئية بسيطة قابلة للتحريك/الاستبدال لاحقًا بأفاتار كامل.
- مشاهد متعددة: غرفة، مطبخ، حديقة، مكتب، استوديو، مختبر.
- Fast / Deep routing محلي.
- ذاكرة محلية للموضوع والملاحظات.
- تحويل النص إلى كلام عبر Android TTS.
- إدخال صوتي عبر خدمة التعرف المتوفرة في الجهاز.
- لوحة خصوصية للمايك والكاميرا.
- توجيه داخلي أولي للصوت/الموسيقى، الفيديو، البرمجة، الصيانة، التعليم العملي والاقتصاد.

## غير مزيف
المحركات التالية لا تعتبر مكتملة قبل ربط خدماتها واختبارها: الأفاتار ثلاثي الأبعاد/الحي، توليد الفيديو، مونتاج وتصدير الفيديو، تحليل pitch/note من ملف صوتي، نماذج AI السحابية، البحث الحي، GitHub execution، البريد والسوشيال والمدفوعات.

القاعدة: لا تظهر ميزة على أنها تعمل إذا كانت مجرد واجهة بدون محرك فعلي.
