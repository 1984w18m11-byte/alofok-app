
# تقويم الأفق V2 — Android + iOS

## ما تم تنفيذه
- مشروع Expo/React Native واحد لـ Android وiPhone.
- GPS واختيار مدينة احتياطي.
- محرك فلكي محلي مستقل: الشمس، القمر، الاستطالة، الإضاءة، بحث اقتران تقريبي.
- وحدة تقييم هلال محلية مرتبطة بغروب الشمس.
- محرك مواقيت صلاة: MWL / Egyptian / Karachi / Umm al-Qura + عصر قياسي/حنفي.
- قاعدة جميع الدول ISO (countries.json) + قاعدة مدن أولية (cities.seed.json).
- بنية قابلة لاستيراد قاعدة عالمية كبيرة مثل GeoNames أو OSM لاحقاً.
- سجل أصوات أذان مرخّصة/غير مرخّصة.
- إشعارات ومناسبات وحزم مذهبية/تاريخية.
- لغات الإصدار: AR/EN/FR/ES، والبنية قابلة للتوسيع عبر BCP-47/CLDR.

## حدود V2 المهمة
1. محرك القمر الحالي أدق من V1 لكنه **محرك فلكي مختصر**، وليس بديلاً عن JPL DE440/DE441 للتحقق العلمي النهائي.
2. معيار الهلال في `crescent.js` يحتاج Validation مقابل الجداول/الخرائط المنشورة قبل تسمية النتيجة «رؤية مؤكدة».
3. قاعدة المدن الأولية ليست كل مدن العالم داخل ZIP؛ الحساب نفسه يعمل بأي إحداثيات GPS. لإضافة كل المدن نستخدم مصدر بيانات عالمي مرخّص ونخزن lat/lon/timezone.
4. لا توجد ملفات أصوات مشاهير في المشروع؛ الأسماء المطلوبة مسجلة فقط بحالة `permission_required`.

## تشغيل
```bash
npm install
npx expo start
```

Android:
```bash
npx expo run:android
```

iOS (يتطلب macOS + Xcode للتجميع المحلي):
```bash
npx expo run:ios
```

## الأذان
- وقت الأذان = المحرك الفلكي حسب الإحداثيات.
- صوت الأذان = حزمة منفصلة.
- لا تُشغّل الحزمة إلا إذا `status = licensed` و`asset` يشير لملف صوتي موجود.

## المدن
`src/data/countries.json` يحتوي قائمة دول ISO.
`src/data/cities.seed.json` يحتوي أمثلة عراقية وسعودية ومصرية وعالمية.
GPS هو المصدر الأفضل للحساب، وقاعدة المدن للبحث والاختيار فقط.
